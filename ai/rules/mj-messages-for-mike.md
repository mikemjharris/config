# Commands, links and PRs in messages to Mike

Mike often reads on his phone. In every reply that asks him to run or open something:

- **Commands** he needs to run go each in its own code block with nothing else in it: no `$` or `!` prefix,
  no comments, no placeholders he has to edit. Several that run together go in one block, joined with `&&`
  where the order matters. Say in the sentence before it what it does and whether it needs `sudo`.
- **Links** he needs to open (GitHub pull requests above all, sites, anything else) are real, tappable
  markdown links, e.g. [infra PR #15](https://github.com/mikemjharris/infra/pull/15). Never put a link in a
  code block.
- **Pull requests to merge go last**: when there are PRs for him to merge, list them at the very end of the
  message, in the order to merge them, after everything else, so they're the last thing he sees.
